Architecture Overview

This project demonstrates how decentralized authorization functions across three independent servers:

PORT 5003

Identity Provider (IDP)

Authenticates users, holds passwords and RSA private key, generates authorization codes, and issues signed RS256 JWT tokens.

PORT 5004

Resource Server (API)

Holds sensitive data. Independently validates incoming Bearer JWTs by downloading public keys from IDP's JWKS endpoint.

PORT 5005

Client App (This App)

The consumer application. Redirects user to IDP for login, exchanges auth code for tokens, and uses access tokens to query API.
